# Nilla's Creations storefront

This directory is the deployable Next.js application. See [the repository README](../README.md) for Square setup, delivery rules, environment variables, catalog management, and the launch checklist.

```bash
npm ci
cp .env.example .env.local
npm run dev
```

Use `npm test`, `npm run lint`, `npm run typecheck`, and `npm run build` before deployment.
